# AGENTS.md

## Flujo de trabajo

- Después de completar y verificar cualquier cambio, **commitear y hacer push siempre**, sin preguntar. Usar mensajes estilo Conventional Commits en español (p. ej. `feat(...)`, `fix(...)`, `chore(...)`).

## Comandos del proyecto

- `npm run lint` — ESLint (flat config)
- `npm run typecheck` — `tsc --noEmit`
- `npm run build` — build de Next.js
- `npm run test:smoke` — smoke test
